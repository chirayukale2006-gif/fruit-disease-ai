# AI-Driven Fruit Disease Decision Support System

An intelligent agricultural advisory system that diagnoses fruit crop diseases using environmental and phytochemical parameters and provides risk-based recommendations.

This project demonstrates a hybrid AI approach combining machine learning prediction and explainable decision support reasoning.

---

## Features
- Multi-crop disease prediction
- Risk level advisory (Low / Moderate / High)
- Explainable output based on plant pathology conditions
- Offline & web deployment support
- User-friendly Streamlit interface

---

## Technologies Used
- Python
- Scikit-learn (Machine Learning)
- Streamlit (Web Interface)
- Pandas
- Joblib
